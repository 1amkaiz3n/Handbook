# Extract URLs & Endpoints dari file js

## Beautify

Kalau file JS minified, langkah pertama:


```bash
js-beautify file.js > file-beautify.js
```

## Cari URL

```bash
grep -aoP 'https?://[^"'"'"'` ]+' file-beautify.js.js | sort -u
```

atau

```bash
gf urls
```

## Cari endpoint dari satu file

```bash
grep -aoP '/[A-Za-z0-9._/?=&%-]+' file-beautify.js.js | sort -u
```

```bash
cat file-beautify.js | gf endpoints | \
grep -viE '\.(png|jpg|jpeg|gif|svg|webp|ico|css|woff|woff2|ttf|eot)(\?|$)' | \
grep -vE '^/[0-9]+px$' | \
sort -u
```

## ambil semua endpoint model dari beberapa file

```bash
grep -rhoP '\$\{r\.apiUrl\}/[^`"]+' js-download/ \
| sed 's#\${r\.apiUrl}##' \
| sort -u
```

## Cari auth

```bash
grep -aoP '(login|logout|signup|register|oauth|token|session|account|user|password)[A-Za-z0-9._/?=&%-]*' file-beautify.js.js | sort -u
```


## Cari API call beneran

Ini yang penting.

```bash
grep -aoP '(fetch|axios|post|get|put|delete)\([^)]+' file-beautify.js.js
```

atau

```bash
grep -aoP 'https?://[^"]+|/[A-Za-z0-9._/-]+(?=["'"'"'])' file-beautify.js.js
```

## Cari base URL yang dipakai Angular HttpClient

```bash
grep -nEi \
'baseUrl|BASE_URL|apiUrl|API_URL|environment|production|endpoint|ENDPOINT' \
file-beautify.js
```

Lalu 

```bash
grep -nEi \
'HttpClient|http\.get|http\.post|http\.put|http\.delete|\.get\(|\.post\(' \
file-beautify.js | head -100
```
